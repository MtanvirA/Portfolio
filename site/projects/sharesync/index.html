ShareSync

DSE Portfolio Tracker & Stock Analytics Platform

ROLE / CONTRIBUTION Full-Stack Software Architecture & Implementation
INSTITUTION PSTU CSE Department
View Repository

Verified Technologies Used

ASP.NET Core (C#) Entity Framework Core MySQL 8 JavaScript Bootstrap 5 Chart.js
Problem Being Solved

The Challenge

Investors in the Dhaka Stock Exchange (DSE) often manage complex multi-transaction portfolios across hundreds of equities without real-time risk indicators, leading to difficulty calculating weighted-average purchase prices, tracking dividend yields, and quantifying annualized volatility and maximum drawdown.

Engineering Solution

The Approach

ShareSync delivers an integrated platform covering over 400+ DSE-listed equities. It provides buy/sell transaction logging, live valuation reports, custom watchlists, and portfolio performance analytics with dynamic Chart.js visualizations backed by MySQL 8.

Architecture & Decisions

System Architecture

Strict Clean Architecture with separated Domain, Service, and Data layers. Uses Repository patterns to abstract database operations, decimal data types to prevent currency calculation errors, and EF Core migrations for deterministic schema versioning.

Verified CV Claims

Analytics & Metrics

Supports CAGR calculation, annualized volatility assessment, maximum drawdown quantification, cash dividend tracking, and ledger audits across historical trading sessions.
