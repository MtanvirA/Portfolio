CampusSync

University Scheduling & Department Coordination Prototype

ROLE / CONTRIBUTION Domain Modeling & Interface Design
INSTITUTION PSTU CSE Department
View Repository

Verified Technologies Used

C# ASP.NET Core MySQL Tailwind CSS JavaScript
Problem Being Solved

The Challenge

University departments face communication friction when coordinating class timetables, lab room assignments, exam schedules, and sudden notices across students and faculty members.

Engineering Solution

The Approach

CampusSync is designed to unify class schedules, lab allocations, faculty consultation hours, and academic announcements into a role-aware web portal for CSE students and faculty.

Architecture & Decisions

System Architecture

Domain-driven schedule conflict detection algorithm designed to prevent double-booking of shared computer laboratories and faculty time slots.

Prioritized mobile-first responsive layout because the vast majority of students access class schedules from smartphones on campus.

Contribution & Scope

My Work & Current Limitations

Conducted requirements analysis for PSTU CSE routine distribution, drafted domain entity models (Batches, Courses, Classrooms, Slots), and created initial interface wireframes.

Current Scope: Prototype stage. Currently undergoing internal validation; not yet institutionalized across the full PSTU administration.
