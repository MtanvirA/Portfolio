CampusSync

Academic Scheduling & Coordination Platform Prototype

ROLE / CONTRIBUTION Prototyping, UI Design & Scheduling Logic
INSTITUTION PSTU CSE Department
View GitHub Repository

Verified Technologies Used

HTML CSS JavaScript SQL Schedule-Conflict Checks Mock Data Demonstration
Problem Being Solved

The Challenge

University departments encounter scheduling friction when coordinating semester routines, available room slots, and teacher availability across batches, frequently risking double-booked classrooms or conflicting periods.

Engineering Solution

The Approach

CampusSync prototypes a focused academic scheduling platform for PSTU CSE. It demonstrates class confirmations, available time slot discovery, and schedule-conflict checks using a structured mock-data dataset.

Prototype Architecture

Scheduling & Conflict Checks

Implements client-side timeslot conflict detection algorithms and relational SQL schema models (courses, teachers, classrooms, time intervals) tested against simulated routine matrices.

Responsive interface built with semantic HTML, modular CSS, and vanilla JavaScript to provide instant schedule visualization.

Verified CV Information

Current Prototype Status

Prototyped specifically for PSTU CSE routine distribution with class confirmations and conflict verification. The current demonstration is powered by mock data.

Scope Notice: Academic demonstration prototype. Not deployed as a production or university-wide live administrative service.
